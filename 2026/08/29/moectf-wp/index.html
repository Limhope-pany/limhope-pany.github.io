三.相关知识点

3.1 静态网页 VS 动态网页

3.1-1 静态网页（文件后缀.html/.htm）

  • 文件本身固定不变：服务器直接把完整的HTML文件发给浏览器，服务器不做计算、不查询数据库
  • 所有内容写死在文件里，页面长什么样，下载到本地就是什么样
  • 可以包含JS：JS是浏览器本地执行，例如本题，成绩数据写在HTML里面的JS代码，所有逻辑在浏览器里跑，不访问服务器拿数据
  • 没有后端程序，没有数据库
  • 缺点：敏感数据直接暴露在源码里，任何人下载HTML就能看到JS里藏的全部数据

3.1-2 动态网页（文件后缀.php/.jsp/.asp/后端接口渲染页面）

  • 服务器会实时运算：不会直接返回写死的文件，浏览器提交请求，服务器执行后端代码，查询数据库，现场拼接生成网页，再发给浏览器
  • 数据保存在服务器数据库，原始数据不会下发到前端
  • 用户输入查询，会把参数传给后端，后端去数据库查成绩，再把结果返回给页面。原始成绩数据库内容，普通用户看不到

这就是该题的flag

三.相关知识点

3.1 HTML注释：<!-- --> 里的内容不会在页面上显示，但查看源码就能看到

3.2 前端安全常识：题目最后一句话点明核心 ——前端隐藏不等于安全。任何放在前端（HTML/JS/CSS）的内容，用户都能通过查看源码获取，不能用来保护敏感信息

二.解题步骤

2.1 拿到PDF附件，打开查看里面的内容，发现没有任何flag，也看不到任何密文

1.1 考点

  • 网页代码审计
  • HTTP数据包（Cookie欺骗、越权）
  • HTTP接口调试
  • URL参数可控

下载WebSocketReflectorX-0.5.2-installer-windows-msvc-x86_64.zip

二.解题步骤

2.1 压缩zip，打开WSRX程序，把题目页面复制的wss://网址粘贴进输入框，点击小飞机图标建立隧道

2.2 连接成功后，本机访问靶场

2.3 在浏览器访问http://127.0.0.1:59733

2.4 Ctrl+U打开网页源代码，Ctrl+F搜索key，记录找到的碎片

2.5 在HTML注释块中可以看到Key2，JS代码：fetch("/getKey?id=3")

2.6 按F12 —— Network(网络)，F5 刷新页面

2.7 在HTML注释块中可以看到Key2—QDBtNG9k，得到Key2

2.8 在浏览器地址栏依次访问

http://127.0.0.1:59733/getKey?id=1 http://127.0.0.1:59733/getKey?id=2 http://127.0.0.1:59733/getKey?id=3 http://127.0.0.1:59733/getKey?id=4 http://127.0.0.1:59733/getKey?id=5 得到Key3-M0szeUVuKw==，Key4-ZXJUaDFzbGE=，Key5-ITkzdA==

2.9 打开Windows cmd，输入curl -i -X POST -H "Cookie: user=admin; Path=/; SameSite=Lax" http://127.0.0.1:59733/getKey?id=4

得到Key6-ZnwxbGFA
